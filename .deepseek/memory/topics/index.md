# 主题索引（导航层）

> 本文件只做**路由**：每个主题一个 `##` 条目，按当前活跃度排序。细节超过 3 行就放 `topics/<slug>.md`，这里只留链接与一行概括。

## 使用说明

条目模板：

```markdown
## <主题名>

- 标签：#标签1 #标签2
- 状态：活跃 / 暂停 / 已收束
- 最新状态截至：YYYY-MM-DD
- 核心笔记：[[笔记名]]
- 一句话概括：……
- 详情：[[topics/<slug>]]（细节、开放问题、相关想法）
```
